# ЖерКөз — цифровой мониторинг земель и сервис для граждан

Прототип (MVP) для **Hackathon by Zhambyl Hub**, кейс «Цифровой мониторинг земель и сервис для граждан».
Двусторонний сервис: **веб-панель земельного инспектора** с картой участков и **Telegram-бот для жителей** г. Тараз.

| | |
|---|---|
| 🌐 Панель инспектора | https://zherkoz.vercel.app |
| 🤖 Telegram-бот | https://t.me/zherkoz_taraz_bot |

> ⚠️ Все участки, кадастровые номера и заявления — **фиктивные тестовые данные** (организаторы подтвердили, что тестовый набор не предоставляется). Код области `99` в кадастровых номерах намеренно несуществующий.

---

## Проблема
Инспекторы тратят время на ручной выездной мониторинг и сверку фактического использования участков с картой. Жителям сложно узнать статус заявления на землю, найти понятный перечень документов и быстро сообщить о заброшенном участке или стихийной свалке рядом с домом.

## Решение — замкнутый цикл
1. Житель в боте отправляет **геолокацию → фото → описание**.
2. Сигнал **за ≤5 секунд** появляется на карте инспектора оранжевой точкой; если точка внутри зарегистрированного участка, участок автоматически становится **жёлтым** («на проверке»).
3. Инспектор берёт сигнал в проверку, подтверждает нарушение, ставит **контрольный срок** и фото.
4. Житель **получает уведомление в Telegram** о каждом изменении статуса своего сигнала.

## Возможности

### Панель инспектора
- Карта (Leaflet + OpenStreetMap) с цветами статуса: 🟩 нарушений нет · 🟨 сигнал / первичная проверка · 🟥 нарушение.
- Карточка участка: кадастровый номер, целевое назначение, площадь, адрес, история действий.
- Жизненный цикл: «Выявлено нарушение» → «В процессе устранения» → «Устранено» / «Возвращено государству» (недопустимые переходы блокируются на сервере).
- Контрольный срок устранения, подсветка **просроченных** участков.
- Загрузка и просмотр фото нарушения.
- Слой сигналов жителей, счётчики, фильтры, поиск по кадастровому номеру, уведомление о новом сигнале.
- Экспорт отчёта CSV (участки, сигналы) для Excel.

### Telegram-бот (только кнопки, без команд)
- **Статус заявления** по трек-номеру: «На рассмотрении», «Назначен выезд инспектора», «Одобрено», «Отказ» с пояснением.
- **База знаний**: изменение целевого назначения, продление аренды, участок под ИЖС — шаги, документы, сроки и ссылки на egov.kz. Контент взят из официальных источников, дата проверки указана в боте.
- **«Народный контроль»**: геопозиция → фото → текст → точка на карте инспектора.
- Два языка: русский и казахский.

| `KZ-2026-042` | Одобрено |

| `KZ-2026-063` | На рассмотрении |
| `KZ-2026-078` | Назначен выезд инспектора |

Сценарий E2E: откройте панель → в боте «📍 Сообщить о нарушении» → отправьте геопозицию (скрепка → Геопозиция → точка на одном из тестовых массивов на окраинах Тараза), фото и текст → точка появится на карте → в панели смените статус сигнала → в боте придёт уведомление.

## Архитектура и стек
```
Житель ── Telegram ──webhook──▶ Next.js Route Handler (grammY)
                                        │
Инспектор ── браузер ──polling 4с──▶ Next.js API ──▶ Upstash Redis (участки, сигналы, заявления)
                                        ├──▶ Vercel Blob (фото инспектора)
                                        └──▶ Telegram getFile (фото жителей через прокси, токен не уходит на клиент)
```
- **Next.js (App Router) + TypeScript + Tailwind**, деплой на **Vercel**.
- **Leaflet / react-leaflet** + тайлы **OpenStreetMap**; геометрия в **GeoJSON** (`[lng, lat]`), привязка точки к участку — **Turf** point-in-polygon.
- **grammY** (webhook, `secret_token`), состояние диалога — в Redis.
- **Upstash Redis** (REST), **Vercel Blob**, валидация — **zod**.
- Секреты только на сервере; `chatId` жителей не отдаётся в панель.

## Запуск локально
Требуется Node.js 20+.
```bash
git clone https://github.com/zxcllxs/zherkoz && cd zherkoz
npm install
cp .env.example .env.local   # заполните значения
npm run dev                  # http://localhost:3000
# загрузить тестовые данные:
curl -X POST -H "x-seed-secret: <SEED_SECRET>" http://localhost:3000/api/seed
```
Для бота нужен публичный HTTPS-адрес (например, деплой на Vercel), затем:
```bash
curl "https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<домен>/api/telegram&secret_token=<TELEGRAM_WEBHOOK_SECRET>"
```

## Переменные окружения
| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | секрет webhook (`secret_token`) |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | Upstash Redis (REST) |
| `BLOB_READ_WRITE_TOKEN` | Vercel Blob (фото инспектора) |

| `NEXT_PUBLIC_zherkoz_taraz_bot` | имя бота (несекретное) |

## Масштабирование
- **Госкадастр.** Модель участка совпадает с базовыми атрибутами кадастра (кадастровый номер, целевое назначение, площадь, границы). Тестовый реестр заменяется загрузкой из информационной системы единого государственного кадастра недвижимости через государственную интеграционную платформу (Smart Bridge).
- **Спутниковый мониторинг.** Открытые снимки Copernicus **Sentinel-2** (10 м, повторная съёмка раз в ~5 дней) позволяют автоматически помечать участки как «сигнал» при отсутствии изменений (неиспользование) — тот же жёлтый статус, что и сигнал жителя. Космический мониторинг уже применяется в РК: по данным Казинформа (август 2026), он выявил 2 642 незаконные свалки.
- **Авторизация инспекторов** через eGov / ЭЦП вместо открытой демо-панели.
